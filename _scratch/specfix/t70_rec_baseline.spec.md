# t70_rec_baseline.spec.md
> 与同名源码双向同步（git4ai 规范）。
## 用途
第四轮基准：**纯 `call :label` 递归**，不含任何帧局部/隔离机制。建立 `call :rec N` 递归本身的
下限成本，作为其他递归隔离机制的对照基线（README 3.7）。
## 对外接口
| 参数 | 默认 | 说明 |
|---|---|---|
| %_N% / %_D% | 首行 set _N=200 / _D=200 | 递归深度（非 ASCII 拦截基准） |
## 关键行为
`:rec` 内 `set /a _SUM+=1`、`_g=%~1-1`、`if !_g! gtr 0 call :rec !_g!`，纯 ASCII 递归。
## 边界与异常
无隔离即无帧数据。深度约 312 触发 cmd 栈限中止；本用例 _D=200 安全。正确性：SUM 须等于 _D。
## 依赖与影响面
独立脚本。作为 t71~t74 各隔离机制的基线对照，结论沉淀 README 3.7。
