## 用途
第四轮基准：**`setlocal`/`endlocal` 帧隔离递归**。每层 setlocal 建立独立环境帧，
帧局部 `v` 写读取用，跨层回传 `_SUM` 用 `endlocal & set "_SUM=%_SUM%"`（README 3.7）。
## 对外接口
| 参数 | 默认 | 说明 |
|---|---|---|
| %_N% / %_D% | 首行 set _N=200 / _D=200 | 递归深度 |
## 关键行为
`:rec` 首行 `setlocal`，块内 `set "v=1"`、`set /a _SUM=_SUM+v`、递归降层，尾行
`endlocal & set "_SUM=%_SUM%"`。正确性：SUM 须等于 _D。
## 边界与异常
每层复制/恢复环境表（t06 单层 ~244µs 价签 D 层摊高）；深度 312 栈限参考。
## 依赖与影响面
独立脚本。验证"setlocal 做递归隔离"的真实价签，作为 t71 `.for-var` 的对照。
