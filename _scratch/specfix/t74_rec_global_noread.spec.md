# t74_rec_global_noread.spec.md
> 与同名源码双向同步（git4ai 规范）。
## 用途
第四轮基准：**自维护全局 index 的"只写不读"最佳形态**。帧局部只写不带读，
数据全走调用参数 `%~1/%~2` 回传，规避 `call set` 间接读（README 3.7）。
## 对外接口
| 参数 | 默认 | 说明 |
|---|---|---|
| %_N% / %_D% | 首行 set _N=200 / _D=200 | 递归深度 |
## 关键行为
`:rec` 首行 `_G.IDX+=1`，`set "_I%_G.IDX%.x=1"` 拼名直写（只写），降层用 `_g=%~1-1`、
`_s=%~2+1`，尾行 `_G.IDX-=1`。结果 `_SUM` 取最深层回传的 `%~2`。
## 边界与异常
只写不读规避 `call set` 双解引用缺陷。验证"间接读"是 global-index 最大的税；深度 312 栈限参考。
## 依赖与影响面
独立脚本。与 t73 对拍定位「间接读 vs 拼名写」的代价归属，是 MAL 帧局部"数据走参数"思路依据。
