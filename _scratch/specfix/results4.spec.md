# results4.csv.spec.md
> 与同名数据文件双向同步（git4ai 规范）。
## 用途
第四轮递归层作用域基准的**原始测量数据**。5 个脚本 t70~t74 在递归深度 50/100/200
三档的耗时（min_ms）与每步均摊成本（µsPerOp = min_ms×1000/N）。供复算/绘制/沉淀 README 3.7。
## 对外接口
| 列 | 类型 | 说明 |
|---|---|---|
| Test | str | 基准脚本名（t70_rec_baseline 等） |
| Arg | str | 深度档位（D=50/100/200） |
| N | int | 递归深度（= D，作为 µsPerOp 分母） |
| min_ms | num | 正式测 3 次的最小耗时（毫秒） |
| usPerOp | num | min_ms×1000/N（每递归步均摊成本，µs） |
## 关键行为
本地盘执行，规避 OneDrive 放大 I/O。warmup 1 次 + 正式测 3 次取最小。
## 边界与异常
非 ASCII 脚本拦截；深度最高 200（远离 ~312 栈限）；此表不包含 stdout，正确性（SUM=_D）见各 .cmd。
## 依赖与影响面
依赖 t70~t74 各脚本输出。结论进入 README 3.7。随 t7x 全套变更。
