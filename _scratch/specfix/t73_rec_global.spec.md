# t73_rec_global.spec.md
> 与同名源码双向同步（git4ai 规范）。
## 用途
第四轮基准：**自维护全局 index 的递归隔离（含间接读）**。不用 setlocal 与 for-var，
每帧用全局计数器拼唯一变量名来隔离，读帧局部走 `call set` 双解引用（README 3.7）。
## 对外接口
| 参数 | 默认 | 说明 |
|---|---|---|
| %_N% / %_D% | 首行 set _N=200 / _D=200 | 递归深度 |
## 关键行为
`:rec` 首行 `_G.IDX+=1` 取帧号，`set "!_nm!=1"` 拼名直写，`call set "_t=%%!_nm!%%"` 间接读，
尾行 `_G.IDX-=1` 释放帧号。正确性：SUM 须等于 _D。
## 边界与异常
间接读依赖 `call set`，对含 `~`/`(` 的字面值有缺陷（与 MAL 已知问题同源）；深度 312 栈限参考。
## 依赖与影响面
独立脚本。验证"自维护全局 index 最快"预判是否成立；不能成立的根因（间接读）由 t74 剥离验证。
